v1.1.1
Made the window wider and squashed a possible bug that kept the window too small if you previously had v1.0.0 of the addon.
Added a settings tab.
 - Toggle to allow horizontal expansion of the window.
 - Toggle minimap button.
 - Select startup window (when doing a /reload or when starting up the game, the addon will open into the selected window).
Added /commands ( /hpf or /nana ) to open the addon via commands, since you now can hide the minimap button.
Added a dropdown to sort to show only rare or common or all pets in the Pet List.
Made it so some windows will resize its content horizontally if resized horizontally. (Pet List & Diets)
Changed so the tooltip in the Pet List is now following your cursor.

V1.1.0
Added a checkbox in the Pet List (Pet Lookup) tab to sort out any pet not tameable at your current level. 
Added a search box where you can type in a zone or name of a pet to sort out pets.
You can now shift-click any pet in the Pet List to write the pet out into chat to let your party know what you're after easier,
Also making the foundation to make each pet clickable in a future update. 
Added tooltips to the Pet List, showing what family and it's bonuses and diets in it to the right of the window.
